# 原代码概况
本项目现有代码是一个`上位机程序`的程序框架.包含:
+ libs
   + broker: 程序内部消息订阅/发布组件
   + guard: 程序的安全保护组件
   + pdf: pdf报告生成组件
   + vsp: 串口服务器通讯组件
   + wf: 程序的`工作流/节点`功能组件
   + logger: 日志组件
   + segs: 传感器数据的分段计算模块

+ runtime
   内置了所有的配置文件

+ ui
   + registry: 所有程序UI窗口的注册管理器
   + view_frame: 程序主程序框架
   + 其他: 其他页面

+ app.ini
   程序的配置文件

+ main.py
   程序的入口文件

# 裁剪说明
上述文件架构是一个`通用的程序框架`, 可以裁剪出一个`特定功能的程序`. 目前我已经删除不需要的组件.
但是当前的主程序`main.py`仍然包含了一些`多余的引用代码`, 需要进一步裁剪.

# 需求
